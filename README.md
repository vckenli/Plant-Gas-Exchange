

## Version 3 simulation logic

- Every scenario starts with **30 O₂ molecules and 30 CO₂ molecules**.
- The displayed counts represent the current simplified gas pool in the simulation.
- Daytime default: photosynthesis rate 8, respiration rate 3, so O₂ increases and CO₂ decreases.
- Night-time: photosynthesis rate 0, respiration rate 3, so O₂ decreases and CO₂ increases.
- Students can optionally enable an **Advanced function** during daytime to adjust light intensity from 0–100%.
- In the simplified advanced model, photosynthesis rate changes from 0–8 relative units according to light intensity.
- When photosynthesis equals respiration, the simulator shows a **compensation point** with no net gas change.
